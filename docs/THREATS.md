# What each red kite tries, and what stops it

Every red Cloudling stands for a real attacker on the internet. That means it can only
aim at something the internet can address: an internet-facing load balancer, or S3's
public endpoint. An EC2 instance in a private subnet has no route from an internet
gateway and only a private address, so no red kite ever aims at one. Reaching such an
instance would take another way in, such as a bastion host and its credentials, which
no attacker in these levels has. A level test checks this rule for every shipped level.

When a red kite is stopped, that is the defence working. It is marked with a green
shield, not a red cross: red crosses mark only faults the player needs to fix (ADR 0009).

| Level             | What the red Cloudling tries                                                                                                                                          | How far its kite gets | What stops it                                       | Why it is realistic                                                                                                                                                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 First Kite      | SSH on port 22 at the load balancer's public address                                                                                                                  | The load balancer     | Its security group, `alb-sg`, allows only HTTPS 443 | Scanning a public endpoint for open ports is the commonest attack on anything internet-facing.                                                                                                                                                           |
| 2 Into the Middle | SSH on port 22 at the load balancer, hoping to reach the servers behind it                                                                                            | The load balancer     | `alb-sg` allows only HTTPS 443                      | The EC2 instances have only private addresses, so the load balancer is the only door. (Until 20 November 2026 this kite aimed at an instance's private address and was shown stopped by "no route"; Simon pointed out that no attacker could aim there.) |
| 3 The Rain Store  | Reading the photo bucket from the internet, HTTPS 443 to S3                                                                                                           | S3                    | Block Public Access on the bucket                   | S3 has a public endpoint; anonymous reads of a misconfigured bucket are a classic data leak, and Block Public Access prevents them.                                                                                                                      |
| 4 Skyway          | The same as Level 3                                                                                                                                                   | S3                    | Block Public Access                                 | Moving the EC2 instances' traffic to a gateway endpoint changes nothing about S3's public endpoint: the bucket must stay private either way.                                                                                                             |
| 5 Crowd Day       | No red Cloudling: the level is about capacity                                                                                                                         |                       |                                                     |                                                                                                                                                                                                                                                          |
| 6 Storm Front     | No red Cloudling: the level is about resilience. The database's security group still matters: chained to `ec2-app-sg`, only the app tier can query it, in either zone |                       |                                                     |                                                                                                                                                                                                                                                          |
